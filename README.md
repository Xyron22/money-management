# MONEY MANAGEMENT By Tenka

Personal money management web app for tracking income, expenses, savings,
emergency funds, monthly budgets, recurring costs, and debt repayments in IDR
or JPY.

Debt records keep the original amount, creditor, start date, remaining balance,
and dated payment history. IDR and JPY debt totals are kept separate from each
other and from the monthly JPY cash-flow balance.
